# Catálogos de Servicios

Dejar en esta carpeta una copia de trabajo de los archivos de catálogos que usa actualmente el área de Servicios.

## Recomendaciones

- Copiar únicamente el Excel de catálogos, no toda la carpeta Dropbox.
- No modificar el archivo original: trabajar sobre una copia.
- Si contiene datos personales, números de documento, teléfonos, domicilios particulares o información financiera innecesaria, avisarlo antes de compartirlo.
- Mantener el nombre original y agregar una nota breve con su origen y fecha de consulta.

El contenido de `docs/insumos/` queda excluido del repositorio porque puede contener información operativa sensible. El Excel se usará primero para identificar catálogos, columnas, códigos y valores reales; no se cargará automáticamente a la base.
