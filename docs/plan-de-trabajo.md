# Plan de trabajo de la rama `feature/mvp-padron`

1. Crear esquema PostgreSQL y migraciones.
2. Implementar ABM de catálogos y puntos de servicio.
3. Implementar búsqueda global y ficha detallada.
4. Implementar cuentas, facturas y estados de pago.
5. Implementar importación por perfiles de proveedor.
6. Implementar documentos, originales y auditoría.
7. Implementar dashboard y exportación de reportes.
8. Agregar permisos, pruebas y despliegue.

Cada etapa debe tener datos de prueba y una validación con usuarios del área antes de avanzar.
